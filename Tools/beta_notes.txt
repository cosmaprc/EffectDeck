The Japanese version follows below.

This beta includes all work in progress, including features not yet in the App Store version. The layout is still being adjusted and may change between builds.

If you updated from an earlier build, restart your iPhone or iPad once, then select EffectDeck again in Control Center. Until you restart, EffectDeck appears in Control Center but does not connect, and the main screen shows a red Restart Required notice. Help opens the issue about it. Please report it if the notice remains after a restart.

New

Output Correction: from the Output Correction row at the bottom of the chain, choose one of your presets for each pair of headphones or speaker. Turn it on with the row's power button. It is applied after the chain, switches automatically when the output changes, and does not modify the chain. Please check it while switching outputs during playback.

EffeTune Remote Control (the Remote Control button in the toolbar) requires an EffeTune desktop build with the LAN remote API. No released version of EffeTune includes it yet, so for now it can only be tested with an EffeTune you build yourself.

Fixes

- Third-party AUv3 plug-ins did not appear under Plugins. Please check that a plug-in and its settings come back after saving and reopening the chain.
- Apple Audio Units such as AUDelay showed only parameter controls instead of their own interface.
- Remote Control showed Connected even when the PC was not responding. It now shows Connected only while the PC responds, and disconnects when responses stop.
- Dropping below the last card failed after Reset chain or deleting a card.

Other

- JSFX scripts run about 1.3 to 1.4 times faster on iPhone, with bit-identical output. Please check heavy scripts for any change in sound or bypassing due to overruns.
- JSFX: fixed a crash or incorrect values when a function using x[] was called more than once, and a crash from file_rewind or file_riff on a handle that is not open.
- Available Effects now has three tabs: Effects, Plugins and Presets. System Presets are one level below the end of Presets, and Import JSFX is at the top of Plugins.
- Effects can be dropped onto the margins, between cards, below the last card and onto an empty chain. On iPad, dropping below the last row of the left list or onto the Output Correction row adds the effect to the end of the chain.

If anything looks or sounds wrong, please use Settings → About → Report a problem and include your device, the output in use and what was playing.

日本語

本ベータ版には、App Store版に未搭載の機能を含む、開発中の内容をすべて収録しています。画面の配置は調整中のため、ビルドごとに変更される場合があります。

以前のビルドから更新した場合は、iPhoneまたはiPadを1回再起動したうえで、コントロールセンターでEffectDeckを選択し直してください。再起動するまでは、コントロールセンターに表示されても接続できず、メイン画面に赤い「Restart Required」が表示されます。Helpを押すと本件のIssueが開きます。再起動後も解消しない場合はご報告ください。

【新機能】

Output Correction：チェーン最下部のOutput Correctionの行から、ヘッドホンやスピーカーごとにユーザープリセットを1つ選択します。有効にするには、行の電源ボタンをオンにしてください。チェーンの後段に適用され、出力先の切り替えに合わせて自動で切り替わります。チェーン自体は変更されません。再生中に出力先を切り替えて動作をご確認ください。

EffeTuneのRemote Control（ツールバーのRemote Controlボタン）には、LANのリモートAPIに対応したデスクトップ版EffeTuneが必要です。対応版はまだ公開されていないため、現時点ではご自身でビルドしたEffeTuneでのみ動作を確認できます。

【不具合の修正】

・他社製のAUv3プラグインがPluginsに表示されない不具合を修正しました。チェーンを保存して開き直したときに、プラグインと設定が復元されるかをご確認ください。
・AUDelayなどApple製のAudio Unitで、専用の画面が表示されずパラメータの表示だけになっていた不具合を修正しました。
・Remote Controlで、PCが応答していない場合でも「Connected」と表示される不具合を修正しました。PCから応答がある間のみ表示し、応答が途絶えた場合は切断します。
・Reset chainやカードの削除の後に、最後のカードの下へドロップできなくなる不具合を修正しました。

【その他】

・JSFXの処理がiPhoneで約1.3〜1.4倍高速になりました。出力はビット単位で従来と同一です。負荷の高いスクリプトで、音の変化や、処理時間の超過によるバイパスが発生しないかをご確認ください。
・JSFXで、x[]を使用する関数を2回以上呼び出すと強制終了する、または値が不正になる不具合と、開いていないハンドルに対してfile_rewindまたはfile_riffを使用すると強制終了する不具合を修正しました。
・Available EffectsをEffects・Plugins・Presetsの3つのタブ構成にしました。System PresetsはPresetsの末尾から1段下の階層、Import JSFXはPluginsの先頭にあります。
・エフェクトを、余白、カードの間、最後のカードの下、空のチェーンにドロップできるようにしました。iPadでは、左の一覧の最後の行より下、またはOutput Correctionの行にドロップすると、チェーンの末尾に追加されます。

表示や音に問題がある場合は、Settings → About → Report a problemから、ご使用の端末、出力先、再生していた内容を添えてご報告ください。
